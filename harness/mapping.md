# 매핑표: 하네스 카드 → 인덱스 HTML 상수

S5(index-writer)가 쓰는 기준이다. 대상 파일: `프로덕트 디자이너 면접 인덱스.html`
HTML 코드를 읽어 확인한 사실과, 제안(기본값)을 구분해서 적는다. 제안은 사용자 확인 전까지 `확인 필요`다.

## 확인된 HTML 구조 (코드에서 읽음)

| 상수 | 형태 | 비고 |
|---|---|---|
| `QGROUPS` | `[카테고리, [항목...]]`의 목록. 항목은 문자열 또는 `[질문, 레벨, 자주 나옴, 답변 문장들, 핵심 키워드]` | 레벨 0=기본, 1=꼬리질문, 2=심화 (`LVS`). 자주 나옴 0/1(⭐). 뒤쪽 값은 생략 가능 |
| `COMPANY` | `{기업명: {kw:[...], qs:[...]}}` | `kw`, `qs`는 둘 다 배열이어야 한다. `qs`의 문자열은 `QGROUPS`의 질문 텍스트와 같으면 메타 정보가 연결된다. |
| `GEN` | `[[라벨, 질문], ...]` | 일반 면접 연습 순서 |
| `CARDS` | `{id, title, one, kw[], sum[], qs[] ...}` | `id`가 있다. 내 사례 카드 |

- `QGROUPS` 항목에 답변 문장(`ans`)이 없을 때는 빈 배열 `[]`이 아니라 **생략**해야 한다. 빈 배열은 참으로 취급되어 "답변" 버튼과 빈 박스가 생긴다.
- 핵심 키워드(`kw`)는 `QGROUPS`에서 답변 박스 안에서만 보인다. 답변 문장이 없으면 질문 쪽에 담을 수 없다.

## 매핑 (제안)

| 하네스 산출물 | 반영 위치 | 형태 | 비고 |
|---|---|---|---|
| 예상 질문·답변 카드의 질문 | `QGROUPS` | 새 카테고리 `{기업명}`에 `[질문, 0, 0]` 추가 | 답변 문장이 없으므로 3요소 형태 |
| 예상 질문·답변 카드의 꼬리 질문 | `QGROUPS` | 같은 카테고리에 `[꼬리 질문, 1, 0]` 추가 | 레벨 1 = 꼬리질문 |
| JD 분석 카드의 핵심 역량 + 질문 목록 | `COMPANY` | `COMPANY['{기업명}'] = {kw: 우선순위 순 핵심 역량, qs: 질문 텍스트}` | 기업 탭에 나타난다. |
| 핵심 키워드, 근거 사례 | 반영하지 않음 | 실행 폴더의 `03-qa.json`에만 남기고 `05-changelog.md`에 기록 | HTML에 대응하는 필드가 없다. |
| 역량 매칭 카드 | 반영하지 않음 | `02-match.json`, `review.md`에만 남긴다. | HTML에 대응하는 상수가 없다. |
| 프로젝트 경험 카드 | 반영하지 않음 | `harness/data/experiences.json`에만 둔다. | `CARDS` 반영 여부는 `확인 필요` |

## 반영 규칙 (PRD·gates.md 기준)

- 추가만 한다. 기존 항목을 수정·삭제·재정렬하지 않는다. 기존 내용은 값까지 그대로 남아 있어야 한다. (G5)
- 수정은 상수 **선언 안에서만** 한다. 선언 밖에서 `COMPANY['…']=…`, `.push()` 같은 방식으로 고치지 않는다. (G5가 걸러 낸다.)
- 새로 들어가는 문자열(질문, 꼬리 질문, 핵심 역량, 기업명)은 승인된 `01-jd-analysis.json`, `03-qa.json`에 있는 것만 쓴다. 새 문구를 만들지 않는다. (G5)
- `COMPANY`에 같은 기업명 키가 이미 있으면 덮어쓰지 않는다. 멈추고 사용자에게 보고한다.
- `QGROUPS`에 같은 질문 텍스트가 이미 있으면 추가하지 않고 `05-changelog.md`에 "이미 있음"으로 기록한다.
- 반영 전 백업(`05-index-before.html`)이 없으면 시작하지 않는다.
- 사용자 승인 기록이 없으면 시작하지 않는다.

## 확인 필요

- `QGROUPS`의 새 카테고리 이름: 기본값은 기업명 그대로
- `GEN`(일반 연습 순서)에도 반영할지: 기본값은 반영하지 않음
- `CARDS`에 프로젝트 경험 카드를 반영할지: 기본값은 이번 구현 범위 밖
- 핵심 키워드를 HTML에 보여 줄 방법: 현재 구조로는 `COMPANY.kw`(기업 단위)만 가능
