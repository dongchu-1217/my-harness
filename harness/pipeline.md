# 파이프라인 (R3)

## 사전 입력 (파이프라인 밖)
- 면접 준비자가 프로젝트 경험 카드(문제 → 행동 → 결과 → 회고)를 추가하고, 추가 완료 시 저장한다.
- 최초에는 경험 카드가 0건이다. 인덱스 HTML의 기존 내용은 S2의 입력이 아니다.

## 단계

| 단계 | 입력 | 출력 | PRD 부록 A |
|---|---|---|---|
| S1 JD 분석 | 기업명, 직무명, JD 원문 | JD 분석 카드 (핵심 역량, 요구 경험, 우선순위) | 1 |
| S2 경험 매칭 | JD 분석 카드, 저장된 경험 카드 | 역량 매칭 카드 (근거 없으면 `경험 부족/확인 필요`) | 2, 3 |
| S3 질문·답변 생성 | 역량 매칭 카드 | 예상 질문·답변 카드 (문제 → 행동 → 결과) | 4 |
| S4 점검 | 카드 3종, 저장된 경험 카드 | 점검 리포트 (중복·사실 불일치) | 5 |
| S5 인덱스 반영 | 확정된 카드 | 수정된 HTML(인덱스에 직접 반영), 반영 전 백업, 변경 이력 | 6 |

## S2 시작 조건
- 저장된 경험 카드 1건 이상. 0건이면 S2를 시작하지 않고 사용자에게 경험 추가를 요청한다.

## 되돌아가는 지점

| 상황 | 복귀 |
|---|---|
| S4에서 02(역량 매칭 카드)의 사실 불일치 | S2 |
| S4에서 03(질문·답변 카드)의 사실 불일치 | S3 |
| S4에서 중복 | S3 |
| 사용자가 반려 | S3 |
| S5 반영 실패 | S5 재시도 |

- 같은 단계로 되돌아오는 횟수 상한: 2회. 초과하면 멈추고 사용자에게 보고한다.

## 사람 승인 지점 (gates.md에서 확정)
- S4와 S5 사이

## 확인 필요
- 경험 카드의 저장 위치와 파일명 (R4에서 정한다.)
