# 게이트 (R5, 독립 리뷰 반영판)

필수 필드는 PRD 4장 산출물 표 기준이다. 판정 로직은 `harness/scripts/judge.py`, 값은 `harness/rules.json`이 원본이다.

## 게이트 표

| 게이트 | 통과 조건 (스크립트가 셀 수 있는 형태) | 실패 시 복귀 |
|---|---|---|
| G1 (S1 끝) | 필수 파일(01, state.json) 존재, JD 분석 카드 필수 필드 3/3(핵심 역량, 요구 경험, 우선순위)이 비어 있지 않음, 기업명·직무명 존재, 항목 1개 이상, 우선순위가 상/중/하, id 형식·중복 위반 0건, 스키마 밖 키 0건 | S1 재시도 |
| G2 (S2 끝) | 모든 요구사항이 "근거 경험 ID 1개 이상(상태 '매칭')" 또는 '경험 부족/확인 필요'로 분류됨(미분류 0건), '경험 부족/확인 필요' 항목은 내 강점·근거가 비어 있음, 참조한 경험 ID가 `harness/data/experiences.json`에 없는 건 0건, 근거는 문자열 ID 목록, 스키마 밖 키 0건 | S2 재시도 |
| G3 (S3 끝) | 질문·답변 카드 필수 필드 4/4(질문, 핵심 키워드, 근거 사례, 꼬리 질문)가 비어 있지 않음(빈 문자열 목록 포함), 근거 사례가 경험 카드 ID를 가리키지 않는 카드 0건, id 형식·중복 위반 0건, 스키마 밖 키 0건 | S3 재시도 |
| G4 (S4 끝) | 02·03 카드 항목에 나온 숫자(단위 포함)와 'A/B' 같은 원문 대조 용어가 **그 항목이 근거로 인용한 경험 카드 원문**에 없는 건 0건, 같은 질문 텍스트의 중복 카드 0건 | 02의 사실 불일치 → S2, 03의 사실 불일치·중복 → S3 |
| 사람 승인 | 사용자 승인 1회 (S4와 S5 사이). 승인 기록(`approved`, `approved_at`, 카드·review.md 해시)이 있고, 해시가 현재 파일과 일치하고, `04-check.json`이 통과이고, **G1~G4를 승인 시점에 다시 판정해 모두 통과** | 반려 → S3 |
| G5 (S5 끝) | 승인 재확인 통과, 백업 해시가 승인 시점의 HTML 해시와 같음, 변경 이력 존재, 자바스크립트 구문 오류 0건, 반영 전 내용이 그대로 남아 있음(추가만), 새로 생긴 문자열이 모두 승인된 카드(01·03)에 있음, 추적 상수를 선언 밖에서 고친 건 0건 | S5 재시도 |

## 공통 규칙
- 같은 단계로 되돌아오는 횟수 상한: 2회. 초과하면 멈추고 사용자에게 보고한다.
- 수치 검증: 숫자와 뒤따르는 단위(목록에 없는 단위는 글자 2개까지)를 함께 비교하는 엄격 일치다. 원문의 숫자-단위 사이 공백만 무시한다. 제외 키(`id`, `근거`, `JD 요구사항` 등)는 카드 항목의 최상위 키에만 적용한다.
- 승인 절차: 사용자가 "승인"이라고 답하면 오케스트레이터가 `judge HASH`로 해시를 얻어 `state.json`에 `approved: true`, `approved_at`, `approved_cards_hash`, `approved_html_hash`를 기록한다. 이후 `APPROVAL`이 통과해야 S5를 시작한다.
- **스크립트의 한계 (사람 승인에서 확인):** 숫자가 없는 허위 서술과 한글 수사(절반, 두 배)는 잡지 못한다. `review.md`의 원문 대조로 사람이 확인한다.

## 필수 필드 (PRD 4장)

| 카드 | 필수 필드 |
|---|---|
| JD 분석 카드 | 핵심 역량, 요구 경험, 우선순위 |
| 역량 매칭 카드 | JD 요구사항, 내 강점, 근거 |
| 프로젝트 경험 카드 | 문제, 행동, 결과, 회고 |
| 예상 질문·답변 카드 | 질문, 핵심 키워드, 근거 사례, 꼬리 질문 |

## ★ 어기면 안 되는 것(story-service.md)과의 대응

| 어기면 안 되는 것 | 걸리는 게이트 |
|---|---|
| 존재하지 않는 성과·경험·수치를 만들지 않는다 | G2 (없는 경험 ID 0건), G4 (인용한 경험 원문에 없는 수치·A/B 0건), G5 (새로 들어가는 문자열은 승인된 카드에 있어야 함) |
| 사용자 검토 후 확정하고, 출처 확인 없이 덮어쓰지 않는다 | 사람 승인 (카드 해시 고정, G1~G4 재판정, 승인 전 S5 시작 불가), G5 (승인 재확인, 백업 해시, 기존 내용 보존) |

## 확인 필요
- 질문 문구의 서수·시간 제한('3가지', '1분')도 숫자라서 G4에 걸린다. 오탐이 잦으면 허용 목록을 둘지 사용자와 정한다.
